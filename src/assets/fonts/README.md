# Bundled site fonts

Downloaded 19 October 2026 from the Google Fonts CSS API and its fonts.gstatic.com assets. Normal-style Latin subsets retain the existing Inter, IBM Plex Mono and Oswald typefaces. Inter and Oswald are variable fonts; IBM Plex Mono has four static weights. Font files are committed so builds and browsers do not download fonts from Google.

Font definitions use `next/font/local`, preserve the existing CSS variables, and use `font-display: swap`. Each family is distributed under the included SIL Open Font License. Licenses come from the respective `ofl` directories in https://github.com/google/fonts.
